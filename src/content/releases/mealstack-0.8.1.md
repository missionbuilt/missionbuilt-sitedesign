- **Fixed the crash when tapping the ingredient search field to put food on a plate.** It hit iOS 26.6.1 every time, which meant plates stayed empty and the day's totals read zero. The search is now a plain field on the page.
- **The quick start has a Back button that returns to the three doors, on a fresh install and after Start over.**
- **The usage-data question is four rows at a glance (what's sent, what never is, that Coach talks to a server, how to turn it off), with the full text one tap away.**
- **Today shows how long since your last meal beside the countdown to the next one.**
- **Tips wait until the setup is done and the usage question is answered, and show one a day instead of stacking.**
